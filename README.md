# Дневник тренировок (PWA для iPhone)

Веб-приложение, которое ставится на экран «Домой» и работает без интернета.
Данные хранятся только на телефоне (localStorage), резервная копия — JSON-файл.

## Возможности
- Тренировки по датам, сгруппированы по месяцам (новые сверху)
- Упражнение → подходы (вес × повторы); подсказка «прошлый раз» и кнопка «Заполнить»
- Поиск по упражнению: сразу видно, какие веса были на каждой тренировке
- Вкладка «Упражнения»: история, рекорд, расчётный 1ПМ, график веса
- Повтор тренировки, переименование/объединение упражнений
- Экспорт/импорт резервной копии

## Структура
- `docs/` — само приложение (статический сайт)
- `tools/make-icons.ps1` — генерация иконок в `docs/icons`

## Публикация (GitHub Pages, бесплатно)
1. Создать репозиторий на GitHub и запушить проект.
2. Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, папка `/docs`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

## Установка на iPhone
Открыть адрес в Safari → «Поделиться» → «На экран „Домой“» → запускать с иконки.
Важно: у иконки на экране «Домой» своё хранилище, отдельное от вкладки Safari —
записывайте тренировки именно в установленном приложении.
